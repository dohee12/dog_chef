# 반려견 음식 근거 데이터

`dog-food-evidence.json` 은 멍슐랭의 섭취 금지·주의 판정, 알레르기 판정, 반려견별 위험 안내에 쓰는 근거 데이터다. 아직 앱 코드에 연결하지 않았고, 수의사 감수 전 초안이다.

## 들어 있는 것

| 칸 | 내용 |
|---|---|
| `toxic_foods` | 위험(`danger`)·주의(`caution`) 재료. 한국어 재료명, 예외어, 이유, 독성 물질, 독성 용량, 증상, 출처 |
| `safe_foods` | 조건부 안전 재료 (익힘, 씨 제거 등 `conditions`). `basis` 가 `stated_safe` 면 출처가 먹여도 된다고 직접 말한 것, `pet_food_ingredient` 면 사료 원료·급여 연구 근거 |
| `allergens` | 알레르기 11종과 개 297마리 기준 비율, 교차반응, 시판 사료 표시 오류 경고, 한국 식품 알레르기 표시 대상 |
| `health_conditions` | 췌장염·결석·구리 간질환·신장병·당뇨: 잘 걸리는 품종, 피할 재료, 영양 기준 |
| `breed_sensitivities` | 품종별로 더 민감한 독성 (예: 진돗개와 양파) |
| `part_hazards` | 과육은 괜찮고 씨·껍질·뼈 같은 부위만 위험한 재료. 빼지 않고 "이 부위를 빼고 주세요" 안내 |
| `nutrition_standard` | 국립축산과학원 영양표준(2024) 성견 1,000kcal당 권장 영양소 27종 (최소·최대) |
| `general_warnings` | 수제식 영양 불균형, 콩류와 심장병(DCM) 조사 |
| `sources` | 출처 목록. 등급 `tier` A(논문·Merck), B(수의 독성센터·정부·수의사 검토 데이터), C(일반 기사) |
| `not_included` | 근거를 찾지 못해 넣지 않은 것과 그 이유 |

## 판정 순서

`danger` > `caution` > `safe`. `part_hazards` 는 판정을 바꾸지 않고 안내만 붙인다. 어느 목록에도 없는 재료는 "확인 안 됨"으로 둔다. 안전으로 추정하지 않는다.

## 만든 방법

1. 원문을 직접 읽었다. 논문은 Europe PMC 의 전문 또는 초록, 그 밖에는 기관 페이지 원문.
2. 개(犬)에 대한 내용만 옮겼다. 다른 동물 수치는 넣지 않았다.
3. `quote` 는 원문 그대로다. 원문 페이지를 내려받아 글자 단위로 대조했다 (2026-11-10, 103건 일치·불일치 0건. FDA 페이지 1건은 자동 내려받기가 막혀 수동 확인). PDF 는 줄바꿈 공백을 무시하고 대조했다.
4. 영양표준 표는 PDF 이미지와 PDF 텍스트 두 가지로 읽어 숫자가 같은지 확인했다.
5. 출처끼리 판정이 다르면 `conflict` 에 적고, 더 높은 등급 출처를 따랐다.

## 고칠 때

- 새 항목에는 `evidence` 를 하나 이상 넣는다. 출처 없는 항목은 넣지 않는다.
- 인용문을 바꾸면 원문과 다시 대조한다.
- 수의사 감수를 받으면 `meta.review_status` 를 바꾼다.
